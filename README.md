# FallSim

Simulateur pédagogique interactif de chute libre. Une balle est lâchée, une
autre est lancée horizontalement : dans le vide, elles atteignent le sol au
même instant.

## Développement

```bash
pnpm install
pnpm dev
```

## Vérifications

```bash
pnpm typecheck
pnpm test
pnpm build
pnpm test:e2e
```
